# 🧩 Pokédex App

The **Pokédex App** is a simple web application built with **HTML, CSS, and JavaScript** that allows users to browse and view details about the first 150 Pokémon. The app fetches data from the public **PokéAPI** and displays Pokémon information in a clean, responsive interface using Bootstrap.

This project was created as part of the **CareerFoundry Full-Stack Immersion Program**.

## 📌 Project Overview

### Purpose

The purpose of this project was to practice **JavaScript fundamentals**, working with **APIs**, and structuring code using the **module pattern**. It also introduced asynchronous JavaScript concepts such as `fetch()` and Promises.

---

## ✨ Features

- Displays a list of the first 150 Pokémon
- Fetches data from an external API
- Shows Pokémon details in a modal:
  - Image
  - Height
  - Weight
  - Types
- Responsive layout using Bootstrap

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 4
- PokéAPI (https://pokeapi.co/)
